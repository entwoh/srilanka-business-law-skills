# Skill authoring guide

Use a lowercase hyphenated folder name. Every skill needs a `SKILL.md` with `name` and `description` YAML frontmatter and a `references/` directory. Keep the entry point concise: state the outcome, boundaries, verification discipline, and which reference to read.

References should explain how to find and assess authority rather than copy legal texts. Add a `last_verified` date in ISO format to a reference that makes time-sensitive claims. Link recurring materials through `shared/`.
